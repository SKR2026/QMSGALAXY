🔑 Gmail App Password Setup:
1. Enable 2-Step Verification on the sender Gmail account.
2. Go to Google Account → Security → App Passwords → generate for "Mail".
3. Run these commands in your Firebase project terminal to store secrets securely:
firebase functions:secrets:set GMAIL_USER firebase functions:secrets:set GMAIL_APP_PASS firebase functions:secrets:set APP_URL 4. Deploy Cloud Functions: cd functions && npm install && firebase deploy --only functions
