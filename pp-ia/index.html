Audit Number Configuration
SUPER ADMIN ONLY
Set a unique prefix for each audit type. Numbers are assigned automatically in continuity per plant per month.
Format: PREFIX-PLANTCODE-NNN  ·  e.g. QMS-YNR-001   LPA-BWL-003   EMS-YNR-002
Customer & Supplier audits are excluded from auto-numbering. Plant code is taken from Plant Management → Code field.
