Create the first Super Admin user:
1Go to Firebase Console → Authentication → Users → Add user
2Enter your email and a password. Note the UID shown after creation.
3Go to Firestore → copqUsers → Add document. Use the UID as the Document ID.
4Add these fields: name (string), email (string), role = super_admin, plant = All
5Sign in above with your email & password. All further users can then be added from within the app.
