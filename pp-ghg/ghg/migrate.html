🔧 CarbonOps Data Migration Tool

READ BEFORE RUNNING. This tool converts the legacy single-doc data model (orgs/{plant}/data/upstream with a rows array) into the new per-row model (orgs/{plant}/upstream/{rowId} with ownership fields).

You must run this as an admin while the new firestore.rules are TEMPORARILY relaxed for migration, OR before deploying the new rules. See the README block at the bottom of this page for the safe procedure.

Procedure (read me)

Recommended migration order:
  1. Back up Firestore (Firebase Console → Firestore → Export).
  2. Deploy migration-mode rules: keep the old rules in place so writes still work.
  3. Open this page, sign in as admin, click Dry Run. Verify the counts.
  4. Click Run Migration. Wait for "Done" in the log.
  5. Spot-check the new collections in Firebase Console.
  6. Deploy the new firestore.rules (the secured per-row version).
  7. Deploy the updated index.html app.
  8. (Optional) Delete the old orgs/<plant>/data/{upstream,transport,manufacturing,downstream} docs once you've confirmed everything works.
